# Contribuição

## Branches
- `feat/<descricao>` para funcionalidades.
- `fix/<descricao>` para correções.
- `hotfix/<descricao>` somente para correções urgentes.

## Commits
Use mensagens objetivas: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.

## Pull Request
Explique objetivo, risco, testes, migrations e rollback quando aplicável.

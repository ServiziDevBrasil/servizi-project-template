# Segurança

- Não armazenar credenciais no repositório.
- Usar princípio do menor privilégio.
- Credenciais de produção não devem ser usadas em testes.
- Credenciais administrativas ficam somente no backend ou no gerenciador seguro do ambiente.
- Revisar RLS/policies quando o modelo de acesso mudar.
- Dependências devem ser auditadas periodicamente.
- Alterações críticas de autenticação, autorização ou dados exigem revisão específica.

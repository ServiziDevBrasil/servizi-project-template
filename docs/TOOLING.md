# Governança de ferramentas

Toda ferramenta usada pelo projeto deve aparecer em `tooling.yml`.

Registrar nome, finalidade, conta, responsável, plano, custo, ambientes, localização das credenciais, classificação de dados, dependências, URL administrativa e plano de saída.

Antes de adicionar ferramenta:
1. Qual problema resolve?
2. Já temos equivalente?
3. Qual custo recorrente e variável?
4. Existe lock-in relevante?
5. Como exportamos dados?
6. Como migramos?
7. Como monitoramos uso e cobrança?
